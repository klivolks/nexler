Welcome to the Nexler installer

Nexler is a scaffolding CLI for the Nexler Go web framework. This installs the nexler command-line tool to /usr/local/nexler and links it onto your PATH at /usr/local/bin/nexler — no shell profile editing needed.

If Go 1.26+ or npm aren't already installed, this installer offers to install them too. Nexler itself doesn't need either to run — Go is only needed to build the apps you scaffold with it, and npm is only needed by nexler add, which vendors front-end packages.

A shortcut is added to /Applications (visible in Launchpad) and your Desktop, opening a Terminal window with nexler help.
